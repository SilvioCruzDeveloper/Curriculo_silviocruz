# Currículo Digital — Silvio Cruz

Currículo online estático feito com HTML, CSS e JavaScript.

## Publicação

Este repositório é publicado pelo GitHub Pages. O arquivo inicial é `index.html`; o PDF para download fica na raiz como `Silvio_Cruz_Curriculo.pdf`.

## Estatísticas de acesso

O site registra visualizações e cliques selecionados via Google Apps Script, com aviso apresentado no rodapé. O projeto Apps Script está em `rastreamento-google/Code.gs`.
